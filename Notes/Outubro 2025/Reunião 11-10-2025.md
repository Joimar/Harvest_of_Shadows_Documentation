

## Ideias
- Fazer uma estrutura para salvar os status defensivos do player
	- Unificar em uma classe onde vão ficar os status base e a soma dos status resultante
	- Facilita para a classe de DamageCalculator para fazer os cálculos de dano
- Implementar mesma classe de status defensivos para os inimigos (e todas as classes que podem sofrer dano)
	- Podemos atribuir valores base para as defesas dos inimigos e alterar conforme necessidade de balanceamento
		- Melhor para testes

### Sugestões de Nome para a classe: 
- DamageableDefensiveStats 
- DefenseModule
- DefenseProfile
